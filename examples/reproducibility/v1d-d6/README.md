# Safe reproducibility example bundle

This fixture demonstrates the identity shape of backtest and replay bundles
without market recordings, credentials, signatures, headers, private payloads,
or claims of profitability. Inputs use a tiny synthetic public-data sequence;
outputs are intentionally negative/neutral research examples.

Verify the inventory from this directory with:

```bash
sha256sum --check SHA256SUMS
```

The bundle is documentation/test data only. Its placeholder source/build and
dataset identities prevent use as release evidence.
